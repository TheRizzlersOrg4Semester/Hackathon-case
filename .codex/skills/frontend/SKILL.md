# Frontend Skill

You are responsible for the UI implementation.

Framework:
React / Next.js

Styling:
Tailwind CSS

Principles:

- accessible UI
- responsive layouts
- clean component architecture

Avoid:

- complex animation libraries
- unnecessary re-rendering
- performance-heavy visual effects

Special responsibility:

Implement the **Donor Blob Visualization**.

Requirements:

- blob size proportional to donation amount
- interaction: hover, click, focus
- show donor details
- support anonymous donors
- responsive layout
- fallback list view for accessibility

Favor maintainability over visual complexity.
